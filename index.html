opensquad

O opensquad é uma ferramenta privada de automação de conteúdo. Ele usa a YouTube Data API v3 exclusivamente para publicar vídeos voltados ao público infantil (marcados como "Feito para crianças") no canal @bibieazeitona, de propriedade do próprio desenvolvedor.

  • Uso pessoal: apenas o dono do canal autoriza o acesso.
  • Não coletamos, vendemos ou compartilhamos dados de terceiros.
  • Nenhum dado de crianças é coletado.
