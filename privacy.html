Política de Privacidade

Última atualização: 16 de outubro de 2026

1. Sobre o aplicativo

O opensquad é uma ferramenta privada, operada pelo seu desenvolvedor, que publica vídeos no canal do YouTube @bibieazeitona usando a YouTube Data API v3.

2. Dados acessados

Ao autorizar o aplicativo, acessamos apenas, na conta Google do dono do canal:

  • permissão para enviar vídeos ao canal (youtube.upload);
  • informações básicas do próprio canal, como nome e identificador (youtube.readonly).

3. Como usamos os dados

Os dados são usados exclusivamente para publicar e verificar vídeos no canal do próprio desenvolvedor. Não usamos os dados para publicidade, perfilamento ou qualquer outra finalidade.

4. Armazenamento e segurança

O token de acesso (refresh token) é armazenado de forma criptografada no servidor privado do desenvolvedor e nunca é publicado ou compartilhado.

5. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. O uso das informações obtidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Crianças

Os vídeos publicados são voltados ao público infantil e marcados como "Feito para crianças". O aplicativo não coleta dados de crianças nem de espectadores.

7. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para solicitar a exclusão dos dados armazenados, entre em contato pelo e-mail abaixo.
